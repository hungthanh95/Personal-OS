# Design system

Calm mission control: warm off-white/light and charcoal/dark surfaces, muted green accent, restrained typography and thin borders. No neon, gamification or chart wall.

- Sidebar 232 px. Main padding 28 px, maximum readable form width 640 px. Context rail 280 px when total width ≥1180 px.
- Spacing scale 4/8/12/16/24/32. Corners 12 px. Borders 1 px. Material 3 accessible controls.
- Typography: platform sans; page heading 28/semibold, section 18/semibold, body 14–16, metadata 12. Strong contrast for primary text; secondary text never encodes status alone.
- Accent green; status conveyed with both words and icons. Priority labeled P1–P3 (P1 highest).
- Session rows emphasize title, time, goal/project context and one primary start action. Additional commands use a menu.
- Today: greeting/date, focus list, contextual weekly totals and Activity Score, Personal Insight.
- Forms have persistent labels, validation, multiline evidence, visible cancel/save states. Dialogs scroll on small windows.
- Empty states explain purpose and offer the relevant create action. Loading and storage errors are explicit.
- Dark/light/system preference persists. Demo workspace is prominently labeled.
- Keyboard focus follows normal Flutter traversal; tooltips explain utilities; shortcuts do not hijack text entry.
